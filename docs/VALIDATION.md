# Validation record

Current Python implementation evidence is generated by:

- `python3 scripts/collect-evidence.py` — pytest, EVM, compile, gas, frontend lint/build.
- `python3 scripts/docker-smoke.py` — actual image build and Python/Next proxy/session/analytics checks.
- `python scripts/browser-smoke.py` with Playwright installed — Chromium desktop/mobile and real local-EVM workflow using a simulated EIP-1193 wallet.

See deliverables/evidence/checks.json, docker-checks.json and browser-smoke.json, plus their logs and local screenshots. The API has 19 pytest cases covering migration, legacy password compatibility, authorization, auditor privacy and read-only controls, wallet proof, receipt decoding/rejection, CSV and analytics. Three EVM tests cover accounting and principal withdrawal while the interest reserve is empty, plus top-up/partial-withdrawal accrual.

Browser automation uses a local Ganache chain and simulated signing adapter. It is not an actual MetaMask extension or public Sepolia test. UI charts group events by recording date, and tests keep integer wei exact in API results.

Ganache falls back to its JavaScript transport on the macOS host. Python dependencies can emit third-party deprecation notices; none are suppressed as evidence of correctness. Prior runtime npm audit results applied to the earlier dependency snapshot; the Python runtime does not inherit a security certification from them. No independent audit, stakeholder pilot, public hosting or live demonstration is claimed.
